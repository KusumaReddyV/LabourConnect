# Labour Connect

Labour Connect is a full-stack MERN application for hiring and managing labour services. It allows clients to hire labourers, track job progress, and manage bookings with role-based access for client, labour, and admin.

---

## Features
- Role-based authentication (Client, Labour, Admin)
- Labour search and booking system
- Job request and status tracking
- Labour profile management
- Earnings tracking for labour
- Admin dashboard for managing users

---

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
